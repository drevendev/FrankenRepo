# FrankenRepo contributor instructions

Read README.md and docs/SPEC_SOURCE.md before changing the product. Preserve the owner's initialization prompt and canonical specification.

Build a playful English gothic laboratory. Keep observed GitHub facts, AI interpretation and imaginary descendants visibly distinct. Never execute donor code, fetch arbitrary user URLs, invent provenance, turn unknown observations into zero, or present fixtures as live inference.

Node 24 / npm 11, TypeScript workspaces, React/Vite, Hono, Zod. Core is browser-safe; adapters and orchestration stay on the server. Keep optional integrations out of the initial browser bundle.

Default MODEL_PROVIDER=disabled. Do not register accounts, use credentials, publish, push, deploy, change external services, spend money, add a card, or run schedulers unless the human explicitly authorizes that action. Local implementation and verification are authorized. Do not modify other repositories.

Required checks after relevant changes: npm run verify; npm run test:e2e after building. Provider mocks are test evidence only. Real model qualification needs a sanitized live receipt and operator review. Keep docs/partners/STATUS.json honest. Gallery and permalink controls require actual durable persistence and consent/removal before enabling.
