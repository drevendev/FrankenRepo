# Demonstration handoff

Current local demonstration: npm ci; npm run dev; open http://127.0.0.1:5173;
use sample donors; inspect real public DNA. Observe the honest unavailable-model
state. This is the implemented foundation, not a complete model-generation demo.

To finish the real vertical slice:

1. Supply/start an installed Gemma model through loopback Ollama or explicitly
   authorize and configure a verified free Cloudflare account.
2. Run npm run test:live with a nonrecorded public donor pair; preserve receipt.
3. In the UI, inspect the same pair, select Cursed, pull lever, observe real job
   stages and result. Check brain/body/curse source IDs and exact model.
4. Save PNG, SVG and alt text. Open both image formats and inspect all text.
5. Repeat Useful and Chaotic; review whether both donors remain recognizable.
6. Exercise quota, timeout, invalid output, cancellation and no-storage state.
7. Record the real captioned 45–60-second sequence in VIDEO_SCRIPT.md.
8. Only after owner-authorized publishing/deployment, verify a stranger can
   reproduce the flow at the actual public URL without payment/card.

Partner evidence requires real service use, not installed SDKs. Gallery, voice,
breeding and optional services are unavailable; omit them from the recording.
