# Карточки для статьи и демонстрации

Редакторская подборка от 28 октября 2026, а не мировой рейтинг смешных
репозиториев. В наличии реальные сохранённые ответы Gemma; авторские идеи ниже
помечены отдельно. Ни текст карточек, ни их исходные receipts не переписывались.
Все результаты — вымышленные потомки, а не отзывы о качестве доноров.

**Не брать в главный кадр:** Gluttonous Neural Scuttler v3 обещает
«automated bug-finding insect» без механизма. Исторический Flasking Filter-Beast
v1 обещает слишком общую автоматизацию. Эти результаты полезны в абзаце про
ошибки модели, но не как доказательство удачной полезной мутации.

## Готовые подписи

Текст подписи — редакторский. Реплика в кавычках взята без изменения из карточки.

- **EN, Scavenging Glider:** “Stop trying to feed me those foreign files, I can't
  steer my legs properly while chewing!” HungryCrab supplied repository digestion;
  DesktopFly supplied simulated motor behavior. Gemma supplied the chewing problem.
  The proposed integration is still speculative.
- **RU, Scavenging Glider:** Краб принёс дайджест репозитория, муха — симуляцию
  движения. Потомок жалуется, что не может жевать чужие файлы и рулить ногами
  одновременно. Смешной характер уже есть; полезный адаптер ещё надо определить.
- **EN, Archivist:** A metaphor walks into the family archive. The archivist
  requests evidence of kinship. A real Gemma output whose technical claims still
  needed editorial review.
- **RU, Archivist:** В семейный архив пришла метафора. Архивариус требует
  доказательства родства. Выдуманная бюрократия — шутка; реальные семейные истории
  и исторические трагедии — нет.

## Более необычные, но объяснимые направления

**Это авторские гипотезы для следующей серии, не ответы Gemma и не готовые
интеграции.** Их нельзя сопровождать сгенерированной карточкой как результатом
реального ритуала. Входы, правила и ограничения выписаны, чтобы следующую
генерацию оценивать по смыслу, а не только по красивому имени.

### HungryCrab + desktop-fly — «Муха на диете из лицензий»

Вход: небольшой готовый дайджест кандидатов на заимствование, с уже проверенной
человеком категорией разрешённого использования каждого. Новый адаптер отображает
разрешённый к просмотру кандидат в стимул приближения мухи, отложенный — в паузу,
запрещённый к копированию — в уход. Выход: анимированная очередь и исходная
карточка с evidence, открываемая человеком. Категории назначает проверка,
движение не решает лицензионный вопрос. Не предполагается, что у desktop-fly
уже есть такой публичный управляющий API: это первый вопрос для прототипа.

Шутка: голодное насекомое вынуждено читать условия перед каждым кусочком.
Связь не требует превращать спайки в поиск багов и даёт наблюдаемое правило.

### Scriptorium + kinship — «Нотариус спорных рассказчиков»

Вход: вручную выбранные семейные воспоминания, представленные как отдельные
текстовые издания, и вручную заведённые записи о людях и источниках. Scriptorium
даёт доступные измерения и source IDs; новый адаптер прикрепляет именно эти
наблюдения к артефакту kinship, сохраняя отдельные записи об утверждениях.
Выход: карточка разногласия — два текста о событии, их измерения, цитаты,
источники и явно незаполненное решение исследователя. Метрики не устанавливают
авторство, правдивость, личность или родство. Поддержка произвольного семейного
текста у Scriptorium не подтверждена; сначала нужен отдельный ingestion path.

Шутка: архивный нотариус требует у каждого рассказчика свидетельство о
происхождении запятой. Полезная задача — не потерять различия между версиями.

### Playmancer + desktop-fly — «Муха, которая выбирает игру дольше игрока»

Основание: [Playmancer README](https://github.com/drevendev/Playmancer/blob/master/README.md)
описывает веса предпочтений, жёсткие фильтры и объяснимые компромиссы;
поведение мухи наблюдалось в сохранённом desktop-fly genome.
Вход: уже рассчитанный Playmancer shortlist с объяснениями. Новый адаптер
отображает допустимые результаты в цели движения; случайное движение мухи
выбирает лишь визуальную остановку среди shortlist, не меняет оценки или фильтры.
Выход: насекомое «приземляется» на карточку игры, где видны исходные компромиссы.
Модель мозга не становится объективным рекомендателем. Неизвестно, можно ли
управлять нужными стимулами без изменения desktop-fly.

Шутка: насекомое с крошечным мозгом честнее человека признаёт нерешительность.
Кандидат для следующего Chaotic; **реального ритуала этой пары ещё нет**.

### Dayflare + Playmancer — «Привратник мимолётной славы»

Основание: [Dayflare README](https://github.com/drevendev/Dayflare/blob/master/README.md)
описывает датированные EN/RU наблюдения внимания, не причинность или прогноз;
Playmancer описывает явные предпочтения и фильтры. Вход: вручную сопоставленные
ID игры и статьи Wikipedia, каталог и конкретный архивный временной интервал.
Новый адаптер выделяет пересечение существующего shortlist с подтверждёнными
наблюдениями, не заменяя пропуски нулями. Выход: объяснимые игровые рекомендации
с датированной справкой о внимании. Если пересечения в наборах нет, результат
честно пуст. Не угадывать ID и не обещать предсказание хитов.

Шутка: привратник пропускает модную игру, только если она действительно подходит
игроку, и каждый раз требует паспорт временного окна.
Кандидат для Useful; **реального ритуала этой пары ещё нет**.

## Пакет для демонстрации

1. Для комического reveal выбрать HungryCrab + desktop-fly, Chaotic.
   Заранее проверить доступную квоту; новый ритуал не обязан повторить эту реплику.
2. Для разбора показать сохранённый SVG/PNG с точным receipt и версией промпта.
   Подпись: **SAVED REAL RUN — 28 Oct 2026; no replay in the application**.
3. Для сравнения открыть Useful-карточку архивариуса и объяснить, почему
   существующий evidence ID ещё не делает sentiment analysis наблюдаемым фактом.
4. Для технически понятного примера взять Flask/jq как контроль.
5. Не подменять сохранённой карточкой прямой эфир. У публичной галереи и permalink
   пока нет реализации; материалы здесь — локальные файлы.
