## Решение по промокредитам

Для этой пачки сначала подтверждаем Free/M0, Browserbase Free, Render Hobby
с Free compute и существующую спонсорскую подписку Sentry. Обязательных новых
промоактиваций для такого варианта нет. Наличие аккаунта и использование API
не заменяют проверку тарифа и остатка квоты.

Render, Backboard и Ultramarine могут иметь полезные предложения в
[Hacktoberfest Promos](https://hacktoberfest.com/my/promos), но факт получения
или применения конкретного купона не подтверждён. Встроенный браузер
перенаправляет на вход MLH. Backboard и Ultramarine относятся к следующей
пачке, поэтому не являются условием готовности этих четырёх сервисов.
Ничего требующего карты, пополнения или платного продления не активировать.

## Состояние работы

Ранее начатые изменения MongoDB-адаптера и приватного архива остаются локальными.
Они не опубликованы и не объявлены полностью проверенной UI-интеграцией.
Новые проекты, подписки, деплои и события Sentry во время аудита не создавались.
Выполненный облачный smoke Browserbase не является публичной демкой или
настоящим ритуалом Gemma; его результат сохранён в
[BROWSERBASE_SMOKE.json](../eval/BROWSERBASE_SMOKE.json).
Проверка хранения MongoDB с ранее созданной реальной карточкой находится в
[MONGODB_STORAGE_SMOKE.json](../eval/MONGODB_STORAGE_SMOKE.json).
Ключи, URI и recovery key не включены в этот документ.

## Sentry: проект создан 31 октября

По прямому разрешению владельца создан отдельный проект `frankenrepo`
в существующей организации `dreven`, платформа Hono, runtime Node,
команда `#hackers`. Выбраны Error Monitoring и Tracing. Другие проекты
и биллинг не менялись. DSN получен со страницы настройки созданного проекта;
SENTRY_DSN, SENTRY_ORG и SENTRY_PROJECT сохранены в локальном .env.
Секреты и DSN в этот документ не включены.

SDK не устанавливался, тестовые события не отправлялись. Создание проекта
и наличие DSN подтверждены интерфейсом; интеграция приложения и приём событий
пока не проверены. Ранее указанная задача создания проекта/DSN закрыта.

## Подтверждение Atlas и Browserbase скриншотами владельца — 31 октября

- Atlas: Tier FREE, занято 143.22 MB из 512 MB (28%), auto-scaling OFF.
  Бесплатный тариф подтверждён. Скриншот не показывает имя кластера;
  привязка к используемому кластеру основана на контексте ответа владельца.
- Browserbase: Free / Current. Интерфейс показывает 0 из 60 browser minutes,
  0 из 3 Agent runs, 0 из 1000 Search calls, 0 из 1000 Fetch calls,
  concurrency 3, Model gateway spend $0.00. Proxy bandwidth недоступен.
  Тариф и отображаемая квота подтверждены. На экране Plan resets указано
  October 30th, 2026; это прошедшая дата относительно аудита, поэтому дату
  следующего сброса и отсутствие задержки счётчиков не считаем проверенными.
- Карта на этих двух скриншотах не показана; её отсутствие заявлено владельцем.
  Карту и платные тарифы во время аудита не добавляли.

Предварительный аудит доступов основной пачки завершён. Это готовность
к планированию реализации, а не подтверждение законченных интеграций:
Sentry ещё не получает события приложения, новая тройка модельных сервисов
прошла только read-only авторизацию, публичный деплой не выполнен.
