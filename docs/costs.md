# Costs and limits

Observed in this initialization: no billable provider inference, no paid account,
no deployment, domain purchase or subscription. npm public package metadata/install
and anonymous GitHub reads were used. Network/electricity are not measured.
This is not a claim that any external account has an unlimited free tier.

Core defaults: model disabled; one concurrent ritual; three generation requests
per fifteen-minute socket-IP bucket; twenty model calls per UTC day per process
including repairs; maximum two calls/ritual; at most 1,000 output tokens/call;
ninety-second model request timeout; no paid fallback. Limits reset on restart.

GitHub: four requests/donor maximum per cache miss, twelve-hour cache, twelve
inspect requests per window. Anonymous upstream quota is shared externally and
must be respected. Failures are typed, never replaced by fabricated facts.

Cloudflare account/model access and free/no-card status have not been verified.
No activation may use a required billing card, overage or automatic upgrade.
Local Ollama installation/download is an explicit operator step; weights/hardware
are not bundled. All optional partner account, credit, license and billing status
remains unverified or blocked in partners/STATUS.json.
