# Changelog

## 0.1.0 — 2026-10-28

First public preview of the FrankenRepo laboratory. Node 24 and npm 11;
source and original code/artwork/audio are MIT, with separately credited OFL fonts.

### Included

- Bounded inspection of two public GitHub repositories with source/commit evidence,
  explicit unknown values and no execution of donor code.
- Server-side Cloudflare/Ollama Gemma adapters, three ritual modes, strict structured
  output and evidence-ID validation, cancellation and bounded repair attempts.
- English gothic browser lab with deterministic SVG creatures, reagent animations,
  optional procedural music/sounds, reduced motion and self-hosted typography.
- Sixteen sample donors, distinct random pairs and a specimen cabinet.
- PNG/SVG birth certificates, alt text and source disclosure.
- Ten unchanged successful local Cloudflare browser receipts and one saved local
  quota stop; editorial inheritance reviews and article/demo card materials.
- Core/API/sample tests, Chromium desktop/mobile journeys and GitHub CI.

### Known limitations

This preview does not supply public application hosting, durable monster storage,
gallery/permalinks or a completed recorded walkthrough. Existing evidence IDs do
not guarantee that model interpretations are supported. Budgets, idempotency and
jobs remain process-local, and reverse-proxy rate limiting needs review before
public generation traffic. Useful/Cursed prompt-v4 qualification is incomplete.

The default model is disabled; credentials and model weights are not distributed.
See [known issues](docs/KNOWN_ISSUES.md), [validation](docs/VALIDATION.md) and
[real model evidence](docs/eval/REAL_RUNS.md).
